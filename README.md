# Flappy Buddy

스페이스바를 눌러 작은 새를 날리고 파이프 장애물 사이를 통과하는 브라우저 게임입니다.

게임 주소: https://shinmiso.github.io/

## 실행 방법

1. https://shinmiso.github.io/ 를 엽니다.
2. 또는 `index.html` 파일을 더블 클릭해 Chrome, Edge 등 웹 브라우저에서 엽니다.
3. 별도의 설치는 필요하지 않습니다.

## 조작 방법

- **스페이스바** 또는 게임 화면 클릭: 시작 및 점프
- **다시 시작** 버튼: 게임을 처음부터 다시 시작

## 점수와 게임 규칙

- 파이프 장애물 하나를 완전히 통과할 때마다 점수가 정확히 1점 올라갑니다.
- 파이프에 부딪히거나 화면 위·바닥에 닿으면 게임이 끝납니다.
- 다시 시작하면 현재 점수는 0점으로 초기화됩니다.
- 생명은 3개이며 충돌할 때마다 1개씩 줄어듭니다. 생명이 남아 있으면 스페이스바를 눌러 계속할 수 있습니다.
- 생명 3개를 모두 잃으면 게임이 끝납니다.
- 최고 점수는 브라우저의 로컬 저장소에 보관됩니다.
